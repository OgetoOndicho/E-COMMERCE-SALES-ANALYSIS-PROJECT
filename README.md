## PROCEDURE OUTLINE
This analysis explored the data in four hierarchical phases.
- 1.1. Data Standardization: Involved correcting spelling mistakes, enduring that each colum accurately reflects its data types. Data standardizing is the foremost step to ensuring that the data presented is accurate and consistent.
- 1.2. Data cleaning: Involved handling of missing values and duplicates. Case example in this project, there were cases of duplication and missing values. For each case, the duplicates were removed thereby ensuring that only distinct values remained. For the missing value at row 36 under Unit_Price column, data imputation was done using the average value (mean) obtained during analysis.
- 1.3. Data Analysis: Data analysis was the third phase, it involved conducting calculations on data so as to obtain answers to key business questions. The phase involved computing calculated columns, descriptive statistics, hypothesis testing and data modeling.
- 1.4. Reporting and Dashboards: Is almost the last phase. Use of Pivot tables to compute and summarize data in quicker way so as to create charts and visuals for presentations.
